# AlinaCoder v0.2 Real Zero-Cost Provider Fabric Hotfix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the published v0.2 conversation path execute the complete approved zero-cost provider atlas with automatic model/provider quota failover and Ollama fallback, then rebuild and republish the release on a new validated SHA.

**Architecture:** Add a normative provider-atlas registry, provider adapters behind a narrow protocol, an `InferenceFabric` orchestrator that reuses the existing zero-cost catalog/router contracts, a DPAPI-backed provider credential vault exposed in the desktop UI, and release gates that prove the desktop path rather than only the abstract router. Paid, trial-only, unsafe-account, unknown, or stale routes remain deny-by-default.

**Tech Stack:** Python stdlib (`urllib`, `json`, dataclasses, pathlib), Windows DPAPI, existing AlinaCoder state store/router, GitHub Actions, PyInstaller, Ollama HTTP API.

**Spec:** `docs/superpowers/specs/2026-09-06-v0.2-real-zero-cost-provider-fabric-hotfix-design.md`

## Global Constraints
- Work on `main` only.
- `MAX_PAID_SPEND_EUR = 0.00`.
- Unknown, stale, unsafe-account, trial-only, or non-zero pricing is ineligible.
- Preserve canonical transcript across provider/model switches.
- Keep local Ollama as final hybrid fallback.
- Do not commit provider API keys or tokens.
- Atlas candidates: Kilo Gateway, Z.AI, SambaNova Cloud, Groq, Cloudflare Workers AI, OpenRouter, Google Gemini API, Mistral, Hugging Face Inference Providers, Tencent TokenHub/Hunyuan, Alibaba Model Studio, SiliconFlow, Scaleway, Ollama local, Ollama Cloud, NVIDIA NIM, Cerebras, OpenCode Zen.
- GitHub Models remains RETIRED/TOMBSTONED unless authoritative GitHub evidence explicitly restores it.
