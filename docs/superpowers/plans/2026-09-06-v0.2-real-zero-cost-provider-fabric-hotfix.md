# AlinaCoder v0.2 Real Zero-Cost Provider Fabric Hotfix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the published v0.2 conversation path execute real zero-cost provider routing with automatic quota failover and Ollama fallback, then rebuild and republish the release on a new validated SHA.

**Architecture:** Add provider adapters behind a narrow protocol, add an `InferenceFabric` orchestrator that reuses the existing zero-cost catalog/router contracts, wire `DesktopWorkbench.send_message()` to the fabric, and make the release gate prove the desktop path rather than only the abstract router. Cloud credentials remain user-supplied and secret; paid/unknown routes stay deny-by-default.

**Tech Stack:** Python stdlib (`urllib`, `json`, dataclasses), existing AlinaCoder state store/router, GitHub Actions, PyInstaller, Ollama HTTP API.

**Spec:** `docs/superpowers/specs/2026-09-06-v0.2-real-zero-cost-provider-fabric-hotfix-design.md`

## Global Constraints
- Work on `main` only.
- No autonomous paid LLM spend.
- Unknown, stale, or non-zero pricing is ineligible.
- Preserve canonical transcript across provider switches.
- Keep local Ollama as final hybrid fallback.
- Do not commit provider API keys or tokens.
